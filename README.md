# here-be-rants

A ranty blog about ranty things. Built with [Zola](https://www.getzola.org/) and a lot of JS/TS hate. Plus love for ASCII style art.

## Run it

Needs Zola 0.23.6 and pnpm.

```sh
pnpm dev   # zola serve on :1111, drafts included
```

Posts are simple markdown and go in `content/posts/`. The `content/posts/kitchen-sink/` post, however, is a test draft with every markdown element possible and should never be published.
